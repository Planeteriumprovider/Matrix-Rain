## <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f4dd/512.webp" width="28" height="28"> Projektbeschreibung

Dieses Projekt ist ein **interaktives, optisch beeindruckendes Hacker-Dashboard**, das im authentischen Terminal-Stil gehalten ist. Es dient ausschließlich dem Zweck, Freunde, Familie oder Mitschüler zu pranken! 

Es sieht verdammt echt aus, ist vollgepackt mit typischen Hollywood-Hacker-Animationen, Ladebalken, Live-Feeds und interaktiven Knöpfen – ist aber zu **100 % harmlos**, läuft rein im Browser und benötigt keinerlei Installation oder Backend-Anbindung. **Reines HTML, CSS (Tailwind) und JavaScript!**

## <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/2728/512.webp" width="28" height="28"> Kern-Features

Das Dashboard ist vollgepackt mit genialen Funktionen, die jeden Prank absolut glaubwürdig machen:

* **<font size="4">🔒 Authentischer Login-Screen</font>**: Bevor das Dashboard startet, muss eine Passworteingabe erfolgen. Das sorgt sofort für eine angespannte "Streng Geheim"-Atmosphäre.
* **<font size="4">⚡ Interaktive Hacking-Tools</font>**: Links befindet sich eine Liste von typischen Sci-Fi-Befehlen. Ein Klick startet automatisierte Terminal-Ausgaben inklusive funktionierender Fortschrittsbalken:
    * *Brute Force WiFi*
    * *Launch DDoS Attacks*
    * *Bypass Firewall*
    * *Decrypt Passwords* (mit animiertem Ladebalken!)
    * *Satellite & Mainframe Access*
* **<font size="4">🌍 Live IP Scan Feed</font>**: Ein simulierter Echtzeit-Hintergrund-Feed, der kontinuierlich zufällige IP-Adressen und Länder (USA, Russland, China, etc.) generiert und scannt.
* **<font size="4">⌨️ Funktionale CLI (Kommandozeile)</font>**: Wer lieber tippt, kann echte Befehle im Terminal eingeben! Tippe `help` ein, um alle verfügbaren Commands wie `scan`, `ddos` oder `mainframe` anzuzeigen.
* **<font size="4">🚨 PANIC BUTTON (Der Rettungsanker)</font>**: Kommt der Lehrer oder die Person, die geprankt wird, plötzlich zu nah? Ein Klick auf den **Panic-Button** (oder das Klicken auf das Tool) tarnt das gesamte Interface sofort als harmloser Windows-Taschenrechner! Mit `ESC` geht es wieder zurück.
* **<font size="4">👾 Glitch-Effekte & Scanlines</font>**: Eine subtile, animierte Scanline läuft permanent über den Bildschirm, kombiniert mit stylischen CSS-Glitches.

* **Framework:** Tailwind CSS v4 (via CDN eingebunden für extremes Leichtgewicht)

* **Architektur:** Monolithisch (Alles in einer einzigen Datei: Struktur, Style und Logik)

## <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f680/512.webp" width="28" height="28"> Installation & Start

Da das Projekt komplett ohne Server auskommt, ist die Einrichtung in unter 5 Sekunden erledigt:

1. Klicke auf die HTML-Datei oder lade dir den Code herunter.
2. Speichere die Datei als `index.html`.
3. Mache einen Doppelklick auf die Datei, um sie im Browser zu öffnen.
4. **Bereit zum Pranken!** 🏴‍☠️
